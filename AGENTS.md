# Работа над foxVPN

Пользователь разрешил публиковать обновления этого проекта в GitHub без повторного запроса подтверждения.

- Репозиторий: https://github.com/kvashninsasha-gif/smart-vpn-router, ветка `main`.
- После законченного и проверенного изменения создавайте коммит и отправляйте его в GitHub. Перед push проверяйте состав файлов; не публикуйте пользовательские профили, резервные копии, URI серверов, ключи или токены.
- При изменении приложения повышайте версию, собирайте macOS Apple Silicon, выпускайте новый предварительный релиз с архивами приложения, исходников и SHA256SUMS. Не заменяйте уже опубликованную версию задним числом.
- Изменения только документации не требуют новой сборки приложения. Отправляйте их в репозиторий.
- При невозможности сборки или push сообщите точную причину. Не выдавайте локальное изменение за опубликованное.
- В 0.1.5 macOS добавлены TUN/helper и PF Kill Switch. Отделяйте реализацию от фактически выполненных системных проверок; сохраняйте точные ограничения из docs/verification-0.1.5.md и docs/coverage.md. Windows системная служба отсутствует. Не выдавайте предварительную сборку за полный MVP.
- Ключ шифрования остаётся в Keychain / Credential Manager. В рамках процесса используйте общий Vault и кеш ключа. Не обходите диалоги macOS путём отключения защиты или расширения доступа к ключам для всех приложений.

- С macOS 0.1.6 после каждого проверенного desktop-релиза также выпускайте подписанные `.app.tar.gz`/`.sig` и обновляйте `updates/macos.json` только после публикации файлов. Порядок и сохранённый локальный ключ: `updates/README.md`. Никогда не генерируйте новый ключ вместо существующего и не публикуйте его. Подписывайте updater-архив только после `seal-macos-bundle.py`; используйте `--app-version` и сохраняйте `requireSignedVersion=true`.
