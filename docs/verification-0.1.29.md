# foxVPN 0.1.29 — подключение и понятная настройка

Дата проверки: 16.10.2026. Код конечных сборок: `ea5c8073c89e9eea96aadb116fed2ebfba024590`. Опубликован предварительный релиз v0.1.29 для Mac и Windows. Все 15 файлов сверены с GitHub по размеру и SHA256 до и после публикации. Обе кнопки скачивания и legacy Mac updater URL подтверждены HTTPS 200 до обновления каналов.

## Что изменилось

Загрузка состояния, подготовка TUN, обращение к компоненту при запуске и выход через меню выполняются в фоне. Status/Logs не удерживают mutex соединения; устаревший ответ не возвращает отключённую сессию. Подхват уже работающего VPN закрывает pending intent. Первоначальное сворачивание не зависит от медленного IPC и не скрывает окно позднее. После подтверждённого Start убран третий дублирующий запрос, но сохранены проверки совместимости, работающих core/DNS, порта и Kill Switch.

Подключение сразу показывает ожидание и прошедшие секунды. Вкладки и отмена доступны до завершения Connect. Отмена ожидает подтверждения остановки; поздний успех и ошибка остановки не подменяются ложным состоянием «Отключено». Автоматический порт проверки резервируется ОС до проверки конфигурации; занятый фиксированный порт по-прежнему отклоняется.

«Проверить и настроить» запускает диагностику до появления ИИ и плана. Backend healthy требует работающего соединения, успешного HTTPS, отсутствия ошибок и устаревания. Для Mac TUN дополнительно обязательны подтверждение core/DNS/порта и HTTPS через системные DNS и маршруты без proxy, таймаут 8 секунд. При успехе показан краткий результат; модель не запускается. При ошибке сначала показаны шаги и конкретный план изменений до подтверждения. ИИ связан с check_id, текущим stamp и сроком 120 секунд. Технические подробности и дополнительные параметры свёрнуты.

## Границы приёмки

До исправления на установленной 0.1.28 остановка helper заняла 0.317 с, локальный порт появился через 0.635 с, подключение завершилось через 1.671 с; пользователь сообщал о >30 с/зависании через окно. Это исходные измерения, а не результат нового GUI. Проверка настоящей кнопки после установки 0.1.29, sleep/wake, смена сети, reboot и полная DNS/IPv6/UDP/QUIC/leak матрица остаются отдельной системной приёмкой.

Физическая проверка Windows-ПК отложена пользователем. Windows остаётся локальным прокси; TUN/WFP Kill Switch для всего ПК не реализован. Developer ID/нотарификация и Windows Authenticode отсутствуют. Остальной план: [subtasks.md](subtasks.md).

Windows EXE: 15 745 009 байт, SHA256 `528ab4fbe34da1f0b5e2f14032f33ae47be0ac7794e1e76b5e1bc63c7b1a7255`. Конечная исходная подпись отдельно проверена на Mac: подмена payload и версии отвергается, сохранённый зашифрованный профиль fixture не меняется. Тесты использовали временные каталоги.
