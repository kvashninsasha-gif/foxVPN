# foxVPN 0.1.12 — уведомление о сетевом компоненте закрывается само

Дата: 06.10.2026. Apple Silicon, arm64. Предварительная сборка; полный MVP по
исходному ТЗ не принят.

## Причина изменения

0.1.11 перестала требовать **повторную** переустановку компонента, но окно
«Обновите сетевой компонент» оставалось открытым и после того, как установщик
macOS успешно завершил работу. Сообщение при этом продолжало висеть:
«Установщик открыт. Завершите установку в macOS, затем нажмите „Проверить
компонент“».

Причина: состояние компонента пересчитывалось только при запуске приложения и по
кнопке. Системный установщик — отдельное приложение, его результат в foxVPN не
возвращается, поэтому после его завершения никто не вызывал `update_state`.

Наблюдение на Mac: 06.10.2026 в 15:58:12 компонент 0.1.11 установлен **один раз**
(повторов не было), `client.cdhash` совпал с CDHash приложения, helper работал, —
но окно осталось открытым, потому что приложение, запущенное в 15:57:50, больше
не проверяло состояние.

## Что изменено

`apps/desktop/src/Updates.tsx`:

- нажатие «Открыть установщик» переводит окно в режим ожидания и запускает опрос
  `update_state` каждые 2,5 секунды (до 24 попыток, около 60 секунд);
- как только компонент становится актуальным, окно закрывается **само**,
  показывается «Сетевой компонент установлен. Можно подключать VPN.» и
  обновляется состояние всего приложения, чтобы кнопка подключения стала
  доступной;
- кнопки «Проверить компонент» и «Позже» остаются доступными; если установку
  отменили, ожидание заканчивается по таймауту и окно возвращается в исходный
  вид с предложением установить компонент.

## Пределы проверки

Поведение окна после реального подтверждения администратора в системном
установщике проверяется на устройстве: автоматические проверки покрывают логику
интерфейса, но не работу системного установщика. После установки 0.1.12 CDHash
приложения меняется, поэтому macOS один раз попросит подтвердить сетевой
компонент и, возможно, доступ к Keychain. Developer ID и нотарификация
отсутствуют.
