# foxVPN 0.1.4 — проверка переименования

Проверка 03.10.2026, MacBook M3, macOS 27.2. Приложение переименовано из Smart VPN Router в foxVPN. Логотип создан как вектор: лисья морда на щите, тёмный синий, оранжевый и светлый кремовый цвета. Тот же знак используется в интерфейсе, favicon и новых иконках macOS/Windows.

- Все 8 существующих тестов Vitest прошли. TypeScript, Vite и native ARM64 Tauri release build прошли. Новых тестов для обратимого изменения оформления не добавлялось.
- Иконки PNG, ICNS, ICO сгенерированы штатной Tauri CLI из SVG. PNG просмотрен; интерфейс просмотрен в браузере и в установленном foxVPN.app. Нативное окно и меню показывают foxVPN, версия интерфейса — 0.1.4.
- Подпись установленной и подготовленной к архивированию копий прошла `codesign --verify --deep --strict`. Проверены CFBundleName=foxVPN, CFBundleIdentifier=ru.smartvpn.router и версия 0.1.4.
- Предыдущая установленная копия закрыта штатным Command-Q и сохранена локально для отката. foxVPN.app установлен в Applications, открылся с прежним сервером и настройками. SHA256 зашифрованного профиля совпал до установки, после неё и после запуска/подключения. Профиль и ключ Keychain не изменялись для ребрендинга.
- На установленной новой копии подключение прошло без повторного выбора режима прокси; настоящий HTTPS-запрос через SOCKS5 127.0.0.1:2080 получил HTTP 204.

Сетевой движок и идентификаторы хранилища не переименовывались; это обеспечивает совместимость существующих профилей. Более широкие сетевые проверки 0.1.3 описаны в `verification-0.1.3.md` и не выдаются за повторённые в 0.1.4. Windows/Intel здесь не тестировались. Системные TUN и Kill Switch остаются нереализованными. Подпись ad-hoc, без Developer ID и нотарификации.
