# Проверка повторных запросов — 0.1.2

Причина исправлена: общий `Arc<Vault>` используется при загрузке и всех сохранениях профиля вместо создания нового Vault при каждой операции. Успешно полученный ключ хранится только в памяти процесса; отказ доступа остаётся ошибкой, которую можно повторить. Ключи и временные буферы защищены `Zeroizing`.

Проверки выполнены на macOS Apple Silicon:

- 41 тест Rust, включая 36 конфигураций настоящего sing-box и реальный локальный VLESS-трафик.
- 160 обращений к общему кешу из 16 потоков: счётчик чтений хранилища равен 1.
- Настоящая изолированная тестовая запись Keychain: после первого сохранения тестовая запись удалена; десять повторных сохранений и чтений через тот же Vault прошли. Новый Vault не смог прочитать профиль без записи Keychain, что подтверждает отсутствие обхода системного хранилища. Пользовательская запись не затрагивалась.
- Отказ чтения не кешируется; успешный повторный доступ кешируется, дальнейшие операции не обращаются к ОС.
- Выбор режима прокси сохраняется после сериализации/загрузки профиля, изменения настроек и выбора другого сервера.
- 5 тестов интерфейса, включая подключение без повторного окна после сохранённого выбора.
- TypeScript/Vite build, `cargo clippy --workspace --all-targets -- -D warnings`, native Tauri release build и `codesign --verify --deep --strict` прошли.

Установленная версия 0.1.2 проверена по Info.plist и подписи; предыдущая сборка сохранена локально. SHA256 пользовательского зашифрованного файла профиля до и после установки/запуска совпал. Ключи и параметры пользовательских серверов не экспортировались.

Первый запуск новой локально подписанной сборки требует системного доступа к Keychain. При нативной проверке активировался SecurityAgent; инструмент управления экраном блокирует доступ к этому системному приложению. Подтверждение оставлено пользователю. Отсутствие повторов диалога в пользовательском GUI после этого подтверждения ещё не проверено вручную; поведение общего Vault проверено автоматическими тестами с настоящей Keychain.

Developer ID отсутствует (`security find-identity -v -p codesigning`: 0 valid identities). Поэтому доверие macOS между обновлениями не гарантируется. Системный TUN, Kill Switch и нотарификация в эту версию не добавлены. Полная инспекция: [permissions.md](permissions.md).
