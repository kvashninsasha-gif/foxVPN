# Трафик торрентов

В foxVPN 0.1.34 откройте «Обзор» → «Трафик торрентов» и выберите:

- **Без VPN — напрямую**: значение по умолчанию, включая прежние профили.
- **Через VPN**: включается только по вашему выбору.

Выбор сохраняется. Менять его можно при работающем VPN: приложение кратко переподключится. При ошибке оно попробует вернуть прежние параметры; при неподтверждённом восстановлении покажет ошибку. Во время применения можно нажать «Отключиться».

Выбор для распознанных MediaGet, µTorrent/uTorrent, qBittorrent и других поддержанных клиентов главнее обычных правил сайтов, исключений приложений и общего режима. Предпросмотр маршрута сайта показывает правила сайта; торрент-клиент дополнительно подчиняется этому выбору. При недоступности выбранного выхода другой автоматически не используется.

На Mac в режиме «VPN всего Mac» нужен сетевой компонент 0.1.34. Встроенное подписанное обновление обновляет его вместе с приложением. В локальном режиме выбор относится только к трафику через foxVPN.

На Windows это локальный прокси, а не системный TUN. Если торрент-программа не использует прокси foxVPN, этот переключатель не может направить её трафик через VPN. Для работы через foxVPN укажите в самой программе SOCKS5: **127.0.0.1** и текущий порт из «Обзора» (обычно **2080**). Установка foxVPN не меняет настройки сторонних торрент-клиентов. Сторонние VPN и прокси приложений не контролируются.

Распознавание BitTorrent дополняет определение программы. Неопределённые соединения с нераспознанным протоколом блокируются; общий системный DNS сохраняет свою политику защиты. Произвольно переименованные клиенты и замаскированный трафик полностью распознать нельзя. Проверки выполнялись на тестовых процессах и локальных peer/VLESS-серверах; настоящие MediaGet/µTorrent на устройстве пользователя не запускались.
