# Проверка исправления подключения — 0.1.1

Исправлена причина сообщения о неподдерживаемой защите при обрыве: кнопка подключения сначала предлагает доступный режим локального прокси; отмена оставляет профиль без изменений. TUN и Kill Switch показаны как недоступные функции. Меню в трее использует тот же сценарий. Подтверждение связано с выбранным сервером, поэтому изменение сервера между показом окна и подтверждением отклоняется.

Проверено: 38 тестов Rust с настоящим sing-box и тестовой записью Keychain; 4 теста интерфейса Vitest — окно выбора вместо ошибочного подключения, отмена без изменения профиля, явный выбор прокси перед подключением, недоступные функции без рабочих переключателей. TypeScript/Vite build и cargo clippy с запретом предупреждений прошли.

Пакет Apple Silicon 0.1.1 собран, локальная подпись codesign проверена. Проверено обновление установленной копии с сохранением предыдущей версии. Пользовательский файл профиля и ключи доступа не изменялись установщиком.

Системный TUN и Kill Switch в этой версии не добавлены. Программа не меняет системный прокси автоматически. Фактическое подключение пользовательского сервера после выбора режима должен выполнить пользователь; при проверке приложения настройки защиты не отключались.

Финальная проверка установленной копии через native UI: отображается версия 0.1.1, сохранённый сервер и его предыдущие измерения; нажатие «Подключиться» открывает окно «Подключение в этой версии» с выбором локального прокси вместо ошибки. Подтверждение подключения не выполнялось, настройки пользователя оставлены без изменений.
