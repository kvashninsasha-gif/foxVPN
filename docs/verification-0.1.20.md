# foxVPN 0.1.20 — обновление Windows с подтверждением

Кнопка «Проверить обновления» доступна на «Обзоре» и в «Настройках» Windows x64 и macOS Apple Silicon. Проверка при запуске отключается пользователем. Скачивание начинается только после «Обновить»; доступны отложенный запуск, пропуск версии и отмена скачивания. Подсказки Windows не предлагают Keychain или компонент macOS.

Windows использует отдельный HTTPS feed и существующий публичный ключ. Допускается только официальный versioned NSIS URL из foxVPN; подпись содержит версию и проверяется до остановки VPN. Несовпадение версии или изменение байтов установщика блокирует установку. Скачивание ограничено 256 МБ и 600 секундами; ошибка или отмена до установки не меняет текущий VPN. Приватный ключ используется локально и в CI не передаётся.

Перед запуском NSIS сохраняется зашифрованный профиль, блокируются новые операции приложения, восстанавливается прежний WinINet-прокси, завершаются ядро и процесс восстановления прокси. При ошибке подготовки установщик не запускается. Установщик показывает прогресс и перезапускает foxVPN. При ошибке запуска установщика VPN уже отключён; пользователь может подключить его снова. Профиль остаётся в прежнем хранилище Credential Manager/APPDATA. В Windows нет автоматического отката бинарных файлов после ошибки или отмены внешнего установщика.

Локально прошли 97 Rust-тестов, 49 frontend-тестов, TypeScript/Vite build и clippy с запретом предупреждений. Интерфейс проверен на Windows-данных: кнопка на «Обзоре», ручной запрос при отключённой автопроверке, отдельный диалог согласия, отсутствие установки без нажатия и отсутствие подсказок macOS. Проверки отмены, ошибок, фокуса диалога и сохранения настроек обновления сохранены.

На Windows runner прошли 86 Rust workspace-тестов, отдельный native WinINet-тест, 49 frontend-тестов, сборка NSIS и две проверки готовых файлов: восстановление прокси в release-EXE после аварии/до чтения повреждённого профиля и фактическая установка 0.1.19 → 0.1.20 с проверкой версии и неизменности файла профиля. Всего 138 проверок. NSIS прогон выполнялся без перезапуска GUI на disposable runner, с явно заданным каталогом установки; сохранность файла профиля не является тестом его дешифрования на личном ПК. CI: https://github.com/kvashninsasha-gif/foxVPN/actions/runs/37937148691.

Mac: 97 Rust + 49 frontend + 2 проверки артефактов — 148 проверок. Подписанный Mac-архив принят, изменение архива/версии отклонено; пакет компонента с текущими владельцем и подписью создан. Бандл arm64 запечатан, Hardened Runtime и подписи ресурсов проверены. Дополнительно локально подписанный Windows NSIS принят, изменение байтов и подмена версии отклонены отдельным тестом. Проверены SHA256 из CI, PE x64 приложения/ядра, встроенная версия 0.1.20 и SHA256 закреплённого sing-box v1.14.2.

Пределы: Windows 0.1.19 и ниже требует одного ручного обновления до 0.1.20. Windows TUN/WFP/Kill Switch не реализованы. Полная последовательность «предложение → подтверждение → скачивание → установка → запуск» на личном ПК ещё не проверена. Mac Developer ID/нотарификация и Windows Authenticode отсутствуют; подпись обновления не заменяет подпись издателя ОС. Нельзя объявлять всю системную матрицу VPN проверенной по тестам updater. Совместимый legacy Mac feed сохранён.
