# Проверка foxVPN 0.1.8

- Rust workspace: 76 тестов прошли, четыре системных/релизных проверки выполняются отдельно или пропущены по условиям.
- Интерфейс: 25 тестов прошли, TypeScript и production Vite build успешны.
- Реальное локальное ядро: проверки VLESS/UDP входят в engine suite. Сохранённые пользовательские серверы не используются.
- macOS arm64 bundle собран, запечатан с Hardened Runtime, подписи и закреплённые ресурсы проверены скриптом.
- Toolchain предупреждает о недоступном libLLVM для удаления debug info; компиляция и упаковка успешны, размер сборки больше оптимального.

Финальный PKG: проверка владельца, подписи, ресурсов и отсутствия профиля прошла без установки. Подписанное обновление 0.1.7 → 0.1.8 в изолированном каталоге и отказ при порче архива прошли. Проверка опубликованного HTTPS дополняется после публикации.

Новая сборка не устанавливалась поверх рабочего VPN 0.1.7. Нативные диалоги 0.1.8, миграция helper на реальном устройстве, Developer ID/notarization, Windows и физический iPhone пока не прошли приёмку. Статус замечаний: security-audit-0.1.8.md.
