# foxVPN 0.1.21 — исправление запуска TUN и управления приложением

## Причина отказа на Mac

sing-box отвергал `detour: direct` в HTTPS-сервере bootstrap DNS: `start dns/https[bootstrap]: detour to an empty direct outbound makes no sense`. Это ошибка создания DNS-транспорта до запуска интерфейса, а не недоступность VPN-сервера. Прежняя классификация ошибок называла её «Не удалось определить адрес сервера».

Bootstrap теперь использует штатный прямой DNS-dialer без лишнего detour; HTTPS и проверка TLS сохраняются. Защищённые DNS-запросы продолжают идти через VPN согласно правилам. Добавлен тест настоящего запуска: старая конфигурация завершается с этой ошибкой, исправленная поднимает локальный порт. Прогон не создаёт TUN, не меняет маршруты/DNS/PF и не отправляет внешние запросы. Проверка `sing-box check` сама по себе проблему не выявляла.

Ошибки запуска сохраняются при обновлении статуса и очищаются после подтверждённого подключения/остановки. Подробности различают проверку конфигурации и запуск процесса; UUID, ключ Reality, shortId, адрес/SNI и API-токен скрываются. macOS-команды из того же подписанного приложения: `--foxvpn-network-status`, `--foxvpn-network-connect`, `--foxvpn-network-stop`, `--foxvpn-network-installer`. Сохраняются проверка владельца, подписи и версии компонента; команды не принимают произвольных конфигураций или путей профиля. Вывод статуса не содержит профиля, server ID или API-токена. Подготовка PKG не устанавливает его и не заменяет подтверждение администратора.

## Интерфейс обеих платформ

Кнопка обновления находится в верхней панели всех вкладок. Найденное обновление можно снова открыть после «Позже». При ошибке загрузки управления обновлениями остаётся повторная проверка; сбой подписки на события не скрывает кнопку. Ошибки ручной проверки видны и вне «Обзора»/«Настроек». Проверки и установка разделены, согласие до скачивания сохранено. На Mac повторное открытие из Dock показывает скрытое окно.

Несохранённые настройки и правила сохраняются поверх свежих снимков; неизменённые поля обновляются из хранилища. Перед сохранением используется свежий снимок, чтобы не затереть новый интервал замеров. Есть отмена локальных изменений. Ошибка проверки автозапуска не отключает подписки на обновления показателей.

Подписки можно редактировать без удаления существующих серверов. Пустые названия, дублирующиеся URL, локальные HTTPS-адреса и отсутствующая подписка обрабатываются без частичного изменения данных. Старый ответ загрузки отклоняется, если URL изменён или подписка удалена. Замена URL сбрасывает дату обновления, последняя импортированная группа серверов сохраняется до нового обновления.

Windows-прокси читается через фактическую конфигурацию WinINet; активный PAC или автоопределение не дают ложного статуса готовности. Сохранённый, но выключенный PAC не считается активным. Устаревший ответ проверки порта не заменяет свежий. Импортированный Mac-профиль не показывает Windows-прокси как VPN всего ПК.

## Проверки

103 Rust-теста, 59 frontend-тестов, TypeScript/Vite build и clippy с запретом предупреждений прошли локально. Дополнительно закреплённое Mac-ядро приняло конфигурацию helper в `check`; тест фактического запуска воспроизвёл прежний отказ и принял исправление. Состав и подписи app/helper/core проверяются при упаковке.

На этом Mac подтверждены работа `utun99`, отдельный UID 62077 ядра, согласованная версия helper, активный системный DNS с `172.29.0.2`/`fdfe:dcba:9876::2`, IPv4-маршрут через utun99 и HTTPS 204 без явного прокси. Helper подтверждает включённый kill switch; независимого чтения PF без прав администратора и полной проверки утечек не выполнялось. `curl -6` также вернул 204, но resolver выдавал IPv4-mapped адреса — это не приёмка нативного IPv6.

Windows runner: 92 workspace Rust-теста, 1 отдельный native WinINet-тест, 59 frontend-тестов и 2 проверки готовых файлов — 154 проверки. Подтверждены восстановление прокси готового EXE до чтения повреждённого профиля и обновление 0.1.19 → 0.1.21 с неизменным файлом профиля. Итоговый CI: https://github.com/kvashninsasha-gif/foxVPN/actions/runs/38039018310. Проверка сохранности файла не является проверкой дешифрования на личном Windows ПК.

Окончательная сборка установлена на Mac атомарно, прежние копии сохранены. Повторный запуск/подключение подтверждены, интерфейс показывает «VPN для ноутбука подключён» без ошибки. Зашифрованный профиль не переносился и ключ не экспортировался. Кнопка обновлений и светлая/тёмная тема проверены отдельно на фиктивных Windows-данных в браузере; это не аппаратная Windows-приёмка.

Windows TUN/WFP/Kill Switch, нативный IPv6/UDP/QUIC leak-test, полная матрица сна/смены сети и подпись издателя обеих платформ остаются открытыми. Прохождение указанных проверок не означает полного выполнения исходного ТЗ.
