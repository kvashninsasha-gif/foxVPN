# foxVPN 0.1.30 — приложения без VPN на Mac

Проверено 22.10.2026. Код конечных сборок: `624e881a121553d1fc14daa102b50e574cdcfab2`. Предварительный [выпуск 0.1.30](https://github.com/kvashninsasha-gif/foxVPN/releases/tag/v0.1.30) опубликован; все 15 assets сверены по размеру и SHA256 после публикации. Тег указывает на указанный код. Оба канала обновления и кнопки скачивания переключены после сверки файлов.

## Функция

В «Маршрутизации» добавлены поиск установленных приложений, выбор `.app` через нативный диалог, удаление и отдельное сохранение списка. Windows App обнаруживается по метаданным пакета; исполняемые файлы не запускаются при выборе. Список хранится в зашифрованном профиле, переносится с ним и не заменяет остальные настройки. Активное/начинающееся подключение и устаревший список блокируют сохранение. Черновик переживает смену вкладок.

Исключённый пакет и его вложенные процессы направляются напрямую во всех режимах Mac TUN, до правил сайтов. Пути экранируются и сопоставляются с границей `/`; похожее имя другого пакета не совпадает. Общий системный DNS остаётся защищённым. В proxy-режиме список сохраняется, но не применяется; Windows не показывает Mac-контролы. План настройки сохраняет исключения и показывает их в охвате.

Ядро сохраняет UID 62077. Только существующий root-компонент через анонимный наследуемый socketpair читает владельца TCP/UDP-соединения. Кадры, объём, тип запроса и таймауты ограничены; возвращаются только пути внутри выбранных пакетов после сверки UID. Команд, PID/путей для произвольного чтения, внешних URL и дополнительного слушающего сетевого порта в протоколе нет. Ошибка определения не включает direct. Подробности и ограничения: [macos-app-exclusions.md](macos-app-exclusions.md).

## Границы

На пользовательском Mac до обновления установлена 0.1.28. Настоящая Windows App/RDP на ноутбуке после установки 0.1.30 ещё не принята. Root-TUN проверка выполнена на сборке того же исходного кода на runner, а не путём переключения VPN ноутбука. IPv6, полная sleep/wake/reboot/leak матрица и внешние службы за пределами выбранного `.app` не объявляются принятыми этим испытанием. Физический Windows-ПК отложен пользователем; Windows TUN/WFP и сертификаты издателя остаются в плане.
