# Покрытие исходного задания

Статус на 03.10.2026. «Реализовано» означает код и перечисленные проверки; не означает успешную приёмку на Windows или выполнение всего ТЗ. На macOS Apple Silicon 0.1.5 проверены обычные HTTPS-запросы через TUN, системный DNS, маршруты IPv4/IPv6, реальный IPv6 HTTPS, браузер, автоподключение и блокировка TCP/DNS при управляемом сбое ядра. Подробности и пределы приёмки — в [verification-0.1.5.md](verification-0.1.5.md).

## Обновление приложения macOS 0.1.6

Реализован отдельный GitHub-канал Mac: проверка при запуске/вручную, согласие до скачивания/установки, «Позже»/пропуск версии, цифровая подпись с привязкой версии, проверка `.app`, сохранение прежней копии и откат ошибки замены. Ядро/сетевой компонент входят в полный подписанный архив; самостоятельного обновления ядра/Geo-баз нет. Подтверждения Keychain и привилегированного компонента macOS сохраняются. Пределы: [verification-0.1.6.md](verification-0.1.6.md).
