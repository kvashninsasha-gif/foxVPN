# Аудит установленного foxVPN 0.1.13

Дата: 06.10.2026. Проверена установленная копия `/Applications/foxVPN.app` на Mac Apple Silicon и текущий исходный код. Это аудит с неразрушающей проверкой рабочего подключения, а не полная системная приёмка.

## Вывод

Базовый VPN на этом Mac работает: GUI показывает подключение TUN, контрольные HTTPS по IPv4 и IPv6 проходят без явно заданного прокси, контрольные маршруты обеих версий IP направлены в utun99. Сетевой компонент и приложение согласованы. Полный MVP и все шесть этапов плана не приняты.

## Подтверждено сейчас

- Установлена 0.1.13. Все 9 обычных файлов приложения совпадают с архивом опубликованного релиза; SHA256 и размеры всех 7 файлов релиза совпали с GitHub.
- `codesign --verify --deep --strict` приложения успешен. Установленные helper и сетевое ядро совпадают с ресурсами приложения, имеют root-владельца, права 0755 и корректные подписи. Подпись приложения ad-hoc, Hardened Runtime включён; идентичности Developer ID нет.
- Привязка CDHash приложения совпадает с установленной; UID владельца совпадает. LaunchDaemon работает. Control socket имеет 0600 и владельца приложения; приватная папка helper — 0700.
- После вывода окна на передний план интерфейс показывает подключённый VPN всего ноутбука, интервал 10 минут, измеренные показатели и отсутствие старого красного сообщения о подключении. При возврате на Обзор показатели изменились с 105 мс / 1,0 Мбит/с на 107 мс / 3,1 Мбит/с без запуска ручного теста в приложении: обновление данных на живой установленной копии наблюдалось. Точная длительность интервала в системном эксперименте не измерялась. Первый пустой снимок фонового окна не считается сбоем: после Raise содержимое доступно.
- TUN utun99 активен. Маршруты к публичным контрольным IPv4/IPv6 идут в utun99. Обычный default остаётся на физическом интерфейсе — это совместимо с отдельными маршрутами TUN, а не доказательство обхода VPN.
- HTTPS `gstatic/generate_204`, без явного прокси: IPv4 — HTTP 204, 0,470 с; IPv6 — HTTP 204, 0,477 с. Это проверка доступности, а не доказательство маршрутизации всех сайтов и отсутствия всех утечек.
- В системном DNS присутствуют резолверы TUN вместе с физическими/scoped резолверами. При умной маршрутизации это само по себе не доказывает ни утечку, ни полное отсутствие утечек.
- Пользователь подтвердил установку через встроенное обновление. Это, вместе с проверенными файлами установленной копии, подтверждает успешный сценарий обновления до 0.1.13 на этом Mac. Обрыв загрузки, отмена и автоматический откат на реальном устройстве этим не проверены.
- Повторно прошли 80 тестов Rust workspace, 34 frontend-теста, отдельная проверка подписанного архива 0.1.13 с установкой/отменой/порчей в изолированном каталоге (всего 115 успешных автоматических проверок), TypeScript/Vite production build; clippy всех targets — без предупреждений. Для тестов ядро временно размещалось на SSD, равенство SHA256 с ресурсом проекта проверено, временная копия удалена.

## Замечания и приоритеты

| Код | Приоритет | Наблюдение | Следующее действие |
|---|---|---|---|
| A1 | Средний | В настройках включено переключение при недоступности, но root TUN восстанавливает тот же сервер. Межсерверное переключение реализовано только для локального режима | Этап 2: реализовать резервы для TUN; до этого явно обозначить ограничение настройки |
| A2 | Средний | TUN заменяет имя сервера IP при Start и сохраняет этот адрес. При смене сети restart использует сохранённый IP | Сохранять исходное имя отдельно, обновлять адрес и PF-разрешение при восстановлении; тест смены DNS |
| A3 | Средний | У восстановления постоянный минимальный интервал 3 с; нет backoff и ограниченного перебора | Ограниченный план попыток, backoff и отмена; тест всех недоступных серверов |
| A4 | Пробел приёмки | Полная матрица IPv6/DNS/UDP/QUIC/исключений/сна/Wi-Fi/аварий не выполнена на 0.1.13 | Этап 3: отдельная системная сессия с контролем утечек и восстановлением |
| A5 | Средний для выпуска | Старая копия сохраняется при обновлении, но полный сценарий автоматического отката при отказе нового запуска не подтверждён; активного CI нет | Этап 4: автоматический rollback/повторный запуск и действующий CI |
| A6 | Ограничение безопасности | Подпись ad-hoc, PKG без Developer ID Installer; экспорт резервной копии не защищён паролем | Этап 5: Developer ID/notarization и переносимый шифрованный backup |
| A7 | Пробел данных документации | Основные таблицы покрытия и плана содержали даты/состояния 04.10 и 0.1.7 | Добавлено текущее уточнение; старые результаты 0.1.5 не считаются приёмкой новой версии |

A1–A3 подтверждены чтением производственного кода `src/bin/foxvpn-helper.rs` (разрешение адреса около строк 275–294, восстановление около 375–400) и отделением локальной ветки failover в desktop. Это незавершённые требования, а не доказанный новый регресс 0.1.13. Состояние PF напрямую прочитать не удалось: `/dev/pf: Permission denied`. Показатель включённого kill switch в GUI не заменяет проверку реального блокирования трафика при обрыве.

| 4. Обновления и выпуск | Успешное встроенное обновление подтверждено пользователем и файлами; релиз/канал согласованы | Частично: rollback, реальные отрицательные сценарии и CI открыты |

Полностью закрытых этапов по всем исходным критериям — 0 из 6. Это не означает «0% функций»: этапы содержат несколько строгих критериев, а базовая работа Mac подтверждена. Процент по числу тестов или этим разнородным этапам не рассчитывается.
