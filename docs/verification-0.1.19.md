# foxVPN 0.1.19 — «Проверить и настроить»

Кнопка доступна на «Обзоре» и в «Настройках» macOS/Windows. Проверки выполняются отдельно от исправлений: целостность ядра, сетевой компонент macOS, активность системного DNS по ответу helper, контрольный HTTPS через текущее подключение и ручной прокси Windows, включая активные флаги сценария/автоопределения WinINet. Сохранённый PAC URL сам по себе не считается активным сценарием. При отключённом VPN проверяются максимум 3 подходящих сервера без скачивания файла скорости; выбранный сервер проверяется первым, учитывается фильтр избранного. В режиме «Напрямую» выполняется запрос без локального прокси с сохранением маршрутов ОС, серверы не перебираются.

При действующем подключении сервер не переключается и соединение не останавливается. Рекомендация выбирается только из успешно проверенных серверов текущего прогона; стратегия может использовать сохранённые показатели скорости/успехов. Изменение выбранного сервера, настроек, правил или подключения делает отчёт неактуальным. Изменённые конфигурации и флаги избранного исключаются из рекомендаций.

Исправления: добавить сервер, выбрать рекомендованный, перейти к существующему диалогу подключения, открыть штатную установку/обновление компонента macOS, либо подтвердить переподключение и автоматическую настройку Windows. Проверка сама не меняет профиль, DNS, прокси или системные маршруты. Установка компонента/настройка Windows требуют отдельного подтверждения в приложении; пароль администратора вводится только в системном окне. Свежая проверка состояния перед подключением предотвращает случайное отключение ставшего активным соединения.

Локально: 97 Rust-тестов, 47 frontend-тестов, TypeScript/Vite build и clippy -D warnings прошли. Тесты покрывают таблицу действий обеих платформ, подтверждение/отмену исправлений, ошибки диагностики, запрет смены сервера при активной сессии и устаревший результат подключения. Windows runner: 81 Rust-тест (80 workspace + 1 отдельный native WinINet), 47 frontend-тестов и проверка готового release-EXE — 129 проверок. macOS: 97 Rust + 47 frontend + 2 проверки артефактов — 146 проверок. Подписанный updater-архив принят, подмена отклонена; пакет компонента с текущими владельцем и подписью создан.

Пределы: HTTPS через локальный порт и сообщения helper не заменяют полный системный leak-test или проверку всех приложений. DNS/IPv6/UDP-утечки не проверяются этой кнопкой. Windows TUN/WFP/Kill Switch и Windows updater отсутствуют; macOS требует системного компонента для VPN всего Mac. Реальная приёмка новой кнопки на личном Mac/ПК ещё не выполнена. Developer ID/нотарификация macOS и Windows Authenticode отсутствуют.

Финальный Windows CI: https://github.com/kvashninsasha-gif/foxVPN/actions/runs/37923684213. Native и release-EXE проверки автоматического восстановления Windows-прокси сохраняются из 0.1.18 и прошли в новой сборке.
