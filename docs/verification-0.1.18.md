# foxVPN 0.1.18 — автоматический прокси Windows

После явного согласия на первом подключении foxVPN проверяет локальное ядро и сервер, затем сохраняет прежние параметры WinINet (флаги ручного прокси, PAC, автоматического определения, адрес и исключения) и включает свой HTTP-прокси. Установщик настройки сети не меняет. Можно выбрать только локальный прокси или выключить автоматическую настройку в настройках приложения. Старое согласие на локальный прокси не разрешает автоматическое изменение сети.

Отдельный непривилегированный процесс текущего пользователя держит канал родителя: EOF при аварийном завершении запускает восстановление. Journal записывается и синхронизируется до изменения Windows. Межпроцессный mutex сериализует сессии; при следующем запуске восстанавливается незавершённая сессия. При нормальном отключении восстановление подтверждается до остановки ядра. Если пользователь/иная программа изменили хотя бы одно из управляемых значений, foxVPN их не затирает. Если прежний ручной прокси уже указывает на текущий порт foxVPN, при отключении он выключается; это объясняется в согласии. Исключения прокси сохраняются.

Пределы: это браузерный прокси совместимых программ, а не Windows TUN/WFP или Kill Switch. При отключении возвращается прежний маршрут. Расширения и собственные параметры программ могут его переопределять. Одновременное принудительное завершение приложения и процесса восстановления оставляет journal до следующего запуска. Отказ Windows/повреждение journal показывается как ошибка, без обещания успешного восстановления. Сравнение текущей конфигурации и восстановление через WinINet не являются атомарной операцией относительно сторонних программ: изменение строго между чтением и записью остаётся гонкой ОС. macOS системные настройки этой функцией не меняются.

Локально прошли 95 Rust-тестов, 42 frontend-теста, TypeScript/Vite build и clippy с -D warnings. Portable-тесты проверяют восстановление PAC/флагов/исключений, прерванную сессию, сохранение внешних изменений, блокировку повреждённого journal переход с ручного foxVPN-прокси, ошибку записи journal и откат после отказа уведомления Windows. Два дополнительных macOS-теста прошли: установка подписанного архива/отклонение подмены и создание пакета сетевого компонента. Native-тест реального WinINet и аварии родительского процесса разрешён только на disposable Windows runner через FOXVPN_TEST_ALLOW_SYSTEM_PROXY=1; результаты будут добавлены после выполнения.

Проверка новой версии на личном ПК пока не выполнена. Authenticode Windows и Developer ID/нотарификация macOS отсутствуют.
