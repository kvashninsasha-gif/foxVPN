# foxVPN 0.1.16 — устойчивость локального прокси

Дата: 07.10.2026.

## Исправления

- Windows-ядро после запуска прикрепляется к отдельному не наследуемому Job Object с KILL_ON_JOB_CLOSE. После назначения ядро завершается при завершении/аварии родительского приложения. При ошибке назначения запущенный процесс принудительно останавливается, запуск не продолжается без защиты жизненного цикла. Это управление процессом, а не сетевой Kill Switch. Окно между spawn и назначением job остаётся; защита атомарного создания процесса не заявляется.
- Ожидание готовности ядра Windows увеличено с 3 до 15 секунд для медленного первого запуска. Другие платформы сохраняют прежний предел.
- Команды подключения/отключения получают номер пользовательского действия. Старое подключение или ошибка не отменяют новое; выход закрывает приём новых подключений до подтверждённой остановки. Ошибка остановки возвращает возможность управления.
- Фоновая проверка локального прокси сравнивает и действие пользователя, и секрет конкретного процесса перед остановкой. Проверка старого соединения не останавливает новое. Фоновый процесс приложения не управляет восстановлением TUN — его выполняет системный компонент.
- Восстановление локального прокси получает отдельные паузы 3/6/12/24/48/60 секунд, по одному кандидату на попытку. Резервы учитывают стратегию и избранное, затем повторяется исходный сервер. Очередь ограничена 31 резервом. Неудачные/неизмеренные серверы остаются доступными для повторной проверки после временного сбоя сети. TUN также получает ранжированные резервы при подключении.
- Исправлено переполнение u64 в расчёте стабильности импортированных серверов. Повторные одинаковые уведомления восстановления подавляются, устаревшая ошибка подключения снимается после восстановления.

## Приёмка

На Mac прошли 88 Rust workspace-тестов с настоящим ядром, 38 frontend-тестов и production build; clippy all-targets без предупреждений. Дополнительные проверки Windows и релиза ещё ожидаются. Установленная копия Mac и действующий VPN не изменялись.

Открыты: физический Windows 10/11 и личный Reality-сервер, длительный прогон, сон/смена Wi-Fi, Windows GUI/Credential Manager/автозапуск. Системная служба Windows/TUN/WFP, автоматическая настройка системного прокси, Windows updater и Authenticode-подпись отсутствуют. При аварийном завершении приложения временный каталог конфигурации может остаться в пользовательском TEMP; автоматическое удаление чужих/непроверенных каталогов не добавлялось.
