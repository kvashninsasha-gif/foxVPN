# foxVPN macOS 0.1.7 — безопасность управления и обновления

Дата: 04.10.2026. Apple Silicon. iPhone остаётся на отдельной версии 0.1.2.
Это предварительная сборка, полный MVP по исходному ТЗ не принят.

## Что изменено

- В установщик сетевого компонента добавлен UID владельца. Helper проверяет
  реальный и эффективный UID из kernel audit token вместе с точным CDHash.
  Сокет имеет права 0600 и принадлежит этому пользователю, файл `client.uid`
  принадлежит root. UID не передаётся в JSON-запросах. При подтверждённой
  администратором смене владельца старая VPN-сессия очищается, её сервер и
  API-секрет не наследуются новой учётной записью.
- Протокол 2 сообщает версию helper, состояние процесса и собственных DNS/PF.
  Старый helper не подтверждает новые возможности и требует обновить пакет.
- Отключение подтверждается только после завершения дочернего ядра, удаления
  собственного DNS и снятия собственной PF-защиты. При отказе DNS защита
  остаётся. Ошибка IPC или неполная очистка показываются как неизвестное
  состояние; GUI сохраняется, установка обновления не переходит к замене.
  Выход из Dock/system Quit также проходит через подтверждение остановки.
- Обновление заменяет `.app` атомарным обменом `RENAME_SWAP`, сохраняет старую
  копию даже при отказе её переименования и не использует два последовательных
  перемещения. Выход при критической установке блокируется, одобренный
  перезапуск разрешён. Проверка миграции helper выполняется вне UI-потока.
  Доступны отмена, управление с клавиатуры и возврат фокуса из окна обновления.

## Пределы проверки

Новая `.app` и новый root helper этими тестами не устанавливались в систему.
Приёмка установленного VPN 0.1.5 не доказывает работу 0.1.7. После установки
приложения требуется один раз обновить «foxVPN-Network» через штатный PKG с
подтверждением администратора; Keychain может отдельно запросить доступ из-за
ad-hoc подписи. Ни пароль, ни доступ к ключам всех приложений не используются.

Фактические DNS/PF-cleanup, запуск/выход из Dock, отказ helper, смена владельца
между двумя macOS-пользователями, перезапуск после реального обновления и
отсутствие утечек требуют системных проверок. Автоматического отката при сбое
запуска новой версии ещё нет; резервная копия сохраняется. Не выполнены
Developer ID/нотарификация, Windows-служба/WFP и физическая VPN-приёмка iPhone.
Заданные TUN-резервы, повторное разрешение адреса сервера и backoff остаются
этапом 2. Все ограничения [0.1.5](verification-0.1.5.md) и
[покрытия](coverage.md) сохраняются. [План готовности](readiness-plan.md).
