# Техническое задание
## Smart VPN Router для macOS и Windows

## 1. Общая концепция

Разработать кроссплатформенное приложение для **macOS и Windows**, которое автоматически распределяет интернет-трафик между прямым подключением и VPN.

Основной сценарий:

```text
Российские сайты → НАПРЯМУЮ
Иностранные сайты → ЧЕРЕЗ VPN
```

Пример:

```text
yandex.ru          → НАПРЯМУЮ
ozon.ru            → НАПРЯМУЮ
sberbank.ru        → НАПРЯМУЮ

youtube.com        → VPN
google.com         → VPN
github.com         → VPN
chatgpt.com        → VPN
```

Пользователь один раз запускает программу, после чего маршрутизация происходит автоматически.

Программа должна объединять функции:

- VPN-клиента;
- менеджера VLESS-серверов;
- split tunneling;
- умной маршрутизации;
- проверки серверов;
- мониторинга соединения;
- управления пользовательскими правилами.

По функциональности менеджера серверов можно ориентироваться на v2rayN, но интерфейс сделать значительно проще и понятнее.

# 4. VPN Core

В качестве сетевого ядра рекомендуется использовать:

- **Xray-core**

или:

- **sing-box**.

Архитектура программы должна позволять в будущем менять или обновлять VPN Core отдельно от GUI.

Core должен запускаться как отдельный управляемый процесс.

Приложение должно:

- создавать конфигурацию;
- запускать Core;
- останавливать Core;
- перезапускать Core;
- получать статус;
- получать статистику;
- читать ошибки;
- автоматически восстанавливать соединение.

Технические ошибки Core должны преобразовываться в понятные русские сообщения.

Например вместо:

```text
connection refused
```

показывать:

```text
Не удалось подключиться к серверу.
Сервер отклонил соединение.
```

При этом в разделе расширенной диагностики можно сохранить исходный технический текст ошибки.

# 62. Требования к качеству перевода

Не использовать машиноподобные формулировки.

Например вместо:

```text
Соединение потерпело неудачу
```

использовать:

```text
Не удалось подключиться к серверу
```

Вместо:

```text
Туннель остановлен
```

использовать:

```text
VPN отключен
```

Вместо:

```text
Прокси недостижим
```

использовать:

```text
Сервер недоступен
```

Формулировки должны быть понятны обычному пользователю.

# 64. Итоговая концепция

Приложение должно работать по принципу:

```text
Установил
↓
Вставил VLESS
↓
Нажал «Подключиться»
↓
Забыл о VPN
```

Дальше приложение самостоятельно определяет:

```text
Российский ресурс → напрямую
Иностранный ресурс → через VPN
```

При этом пользователь получает простой русскоязычный интерфейс для:

- добавления серверов;
- тестирования серверов;
- проверки скорости;
- выбора лучшего VPN;
- настройки исключений;
- просмотра состояния соединения.
