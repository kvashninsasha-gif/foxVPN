# Проверка сборки 0.1.0 — 03.10.2026

Платформа проверки: macOS 27.2, Apple Silicon ARM64. Минимальная версия в пакете — macOS 13.0; на macOS 13 отдельная проверка не выполнена.

- Rust: 32 успешно завершённых теста, включая явно включённый тест системного Keychain. 28 тестов парсера/маршрутизации/шифрования/конфигурации, 3 теста запуска и локального VLESS, 1 тест Keychain.
- Проверены 36 вариантов конфигурации реальным sing-box 1.14.2: 4 режима × 3 транспорта × 3 варианта защиты.
- Реальный локальный VLESS: клиент sing-box → сервер sing-box → HTTP-получатель. Получены ожидаемые данные; API статистики вернул ненулевые счётчики. После отключения процесс остановлен, порт освобождён, временная конфигурация удалена.
- Прямое доменное исключение: локальный сайт доступен при недоступном VLESS-сервере.
- Защита при обрыве: проверено, что неподдерживаемый Kill Switch блокирует подключение.
- Keychain: отдельная тестовая запись создана; зашифрованный профиль записан и прочитан; UUID не содержится в открытом виде; тестовая запись и файлы удалены.
- Проверены изменение/повреждение зашифрованного профиля и несовпадение внутренних параметров безопасности в резервной копии: данные отклоняются.
- TypeScript typecheck + production Vite build прошли.
- cargo clippy --workspace --all-targets -- -D warnings прошёл.
- npm install/audit: 0 известных уязвимостей на момент проверки.
- macOS .app собрана и запущена как native-приложение с tauri://localhost. Русский начальный экран отображается; команда подключения без сервера возвращает понятное сообщение.
- Проверены окно импорта и ручное добавление в браузерном предпросмотре; навигация доступна с русскими accessibility-labels.
- Пакет имеет локальную ad-hoc подпись; codesign --verify --deep --strict прошёл. Developer ID и notarization отсутствуют.
- SHA256 встроенного sing-box совпадает с официальным бинарником, официальный архив проверен по digest GitHub release.

Не проверены: удалённый пользовательский VPN/Reality (профиль не предоставлен), системный TUN, Kill Switch, DNS/IPv6 leak-test, сон/перезагрузка/смена Wi-Fi, Windows 10/11, Intel macOS, реальные HTTP-подписки и внешний тест скорости. Проверка синтаксиса конфигурации не заменяет эти сетевые и системные испытания.
