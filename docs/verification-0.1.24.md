# foxVPN 0.1.24 — испытание подписанного перехода после bootstrap

Код автоматического обновления введён в [0.1.23](verification-0.1.23.md): один раз требуется установка нового компонента вместо legacy протокола 3. 0.1.24 — следующий подписанный релиз для проверки перехода после этого bootstrap.

Добавлен отдельный тест полной подготовки component slot из настоящего подписанного архива: production-верификатор, строгая распаковка, подпись/архитектура app/helper/core, фактическая версия helper, новая привязка и SHA256. Всё выполняется в временных папках от обычного пользователя; системный сервис и root-owned папки не затрагиваются. В production путь входного архива остаётся фиксированным dropbox владельца; тест использует закрытое внутреннее поле для своего временного каталога, это не параметр IPC/GUI.

115 Rust-тестов, clippy с запретом предупреждений, TypeScript/Vite build и прошлый прогон 60 UI-тестов подтверждены для неизменённого поведения интерфейса. Дополнительный тест настоящего архива и системная проверка отмечаются ниже только после результата.

Запрос Keychain при смене ad-hoc подписи остаётся возможным. Windows — локальный прокси. Developer ID, нотарификация, Authenticode, полная системная leak/sleep/network-switch матрица и Windows hardware acceptance остаются открытыми. Наличие кода или проверки временных папок не подтверждает автоматическое обновление установленного root daemon без повторного Installer.

## Проверка реального signed bundle

Локально пройден explicit тест `actual_signed_bundle_is_prepared_without_changing_system_component` на окончательном архиве 0.1.24. Он подготовил настоящий helper/core/binding, проверил фактическую версию и новую app CDHash, сохранил исходную временную slot/floor 0.1.23 без изменения системного сервиса; произвольный путь за пределами dropbox и неправильная версия отвергнуты. Отдельный root-верификатор принял оригинальные bytes и версию, а подмены отверг. Оба ядра из готового app прошли 72 старта и прежний DNS regression. Это подтверждение подготовки, не факт установки root-обновления на ноутбуке.

## Готовые файлы и CI

GUI-верификатор подписанного Mac updater прошёл атомарную замену и отклонение повреждённого архива/неверной версии. Windows EXE принят исходным ключом, подмена bytes/версии отвергнута. Архитектура/версия и SHA256 ядра извлечённого NSIS проверены. macOS CI: https://github.com/kvashninsasha-gif/foxVPN/actions/runs/38060523064 — успешно. Windows CI: https://github.com/kvashninsasha-gif/foxVPN/actions/runs/38060523106 — успешно; 99 workspace Rust + 1 native WinINet, 60 UI, guardian, NSIS update/profile preservation и 72 starts установленного core.

На ноутбуке 0.1.23 установилась через встроенное обновление 0.1.22. На момент подготовки отчёта однократная установка протокола 4 ожидает подтверждения пользователя в системном окне. Переход root-сервиса 0.1.23 → 0.1.24 не объявляется выполненным до системного результата.
