# foxVPN 0.1.15 — подготовка Windows-прокси

Дата: 07.10.2026.

## Изменения

- Snapshot сообщает платформу. Windows-интерфейс показывает точный охват локального прокси и скрывает macOS-установщик/проверку TUN-защиты. Подключение сохраняет явное согласие на прокси; автоматического понижения защиты нет.
- Перед запуском локального ядра и отдельным измерением проверяются ограниченные по размеру файлы, SHA256 и платформа из упакованной metadata. Несовпадение возвращает понятное сообщение о переустановке.
- Новая диагностика показывает версию, платформу, архитектуру, наличие/целостность ядра, состояние и локальный порт. Отчёт не включает профили, URI, серверные адреса, ключи и логи.
- Windows-процессы ядра и проверки конфигурации запускаются без отдельного консольного окна.
- Скрипт загрузки сохраняет также core/sing-box.exe для прямого запуска/тестов Windows. Подготовлен workflow Windows для Rust/реального локального VLESS, frontend-тестов и сборки NSIS с контрольной суммой (ci/windows.yml). Активация в .github/workflows требует GitHub workflow scope. Конфигурация tauri.windows.conf.json явно применяется при сборке.

## Открытые ограничения

Windows-служба TUN, WFP Kill Switch, управление системным DNS/прокси, signed Windows updater и Authenticode-подпись отсутствуют. Системные параметры не изменяются приложением. Проверка в GitHub runner не подтверждает работу пользовательского Reality-сервера, браузера и конкретного Windows ПК. Инструкция: [вечерняя проверка](windows-test-guide.md).

На Mac прошли 83 теста Rust workspace (с настоящим sing-box), 37 frontend-тестов, TypeScript/Vite production build и clippy all-targets с запретом предупреждений. Сборка и тесты Windows ещё ожидаются. Рабочее приложение Mac не заменялось и VPN не прерывался.

GitHub отклонил добавление .github/workflows/windows.yml текущим OAuth-подключением без workflow scope. Код опубликован отдельно; авторизация для Windows runner запрошена. Windows-тесты и новый NSIS пока не выполнены.
