# foxVPN 0.1.15 — Windows-прокси для проверки

Дата: 07.10.2026.

## Изменения

- Windows-интерфейс показывает охват локального HTTP/SOCKS-прокси и скрывает macOS-установщик/проверку TUN-защиты. Подключение сохраняет явное согласие на прокси; автоматического понижения защиты нет.
- Перед запуском локального ядра и отдельным измерением проверяются ограниченные по размеру обычные файлы, SHA256 и платформа из упакованной metadata. Несовпадение возвращает сообщение о переустановке.
- Диагностика показывает версию, платформу, архитектуру, наличие/целостность ядра, состояние и локальный порт. Отчёт не включает профили, URI, серверные адреса, ключи и логи.
- Windows-процессы ядра и проверки конфигурации запускаются без отдельного консольного окна. Скрипт загрузки поддерживает UTF-8 в перенаправленной Windows-консоли и сохраняет core/sing-box.exe для прямого запуска тестов.
- Активирован .github/workflows/windows.yml: тесты Rust/реального локального VLESS, frontend, сборка NSIS и SHA256. Права workflow подтверждены через GitHub CLI; шаблон сохранён в ci/windows.yml. Для Windows явно применяется tauri.windows.conf.json.

## Подтверждённые проверки

На Mac: 83 Rust workspace-теста с закреплённым sing-box, 37 frontend-тестов, TypeScript/Vite production build и clippy all-targets с запретом предупреждений прошли. Arm64 app собран и запечатан; updater-архив подписан сохранённым ключом. Дополнительно прошли явные тесты подписанного обновления (изолированный каталог, отмена, повреждение/версия) и состава PKG; всего 122 успешных локальных автоматических проверки. ZIP приложения проверен по CRC. Сохраняется известное предупреждение rust-objcopy об отсутствующей libLLVM при удалении debug info; сборка успешно завершена.

На Windows Server 2025 в GitHub runner: 64 Rust-теста, включая настоящий локальный VLESS, прямые исключения и проверку конфигураций sing-box, и 37 frontend-тестов прошли (101 проверка). NSIS собран. Успешный запуск: https://github.com/kvashninsasha-gif/smart-vpn-router/actions/runs/37604210037, исходный commit e99d1ed2c9d1c1a8f12a8a70b317cda83d94c633.

Скачанный foxVPN_0.1.15_x64-setup.exe совпадает с SHA256 из CI: 38da930341121cba777d1e89ffd7128a8ac4039a6a65daa9a40a3cc01f310732, 23 182 215 байт. Установщик распакован статическим анализатором: app и core — PE x64, версия app 0.1.15, metadata windows-amd64/v1.14.2, встроенный core совпадает с закреплённым SHA256 7bbef1dea9189ee12799ae834ea4b4658355da25c47a21ad8804904c0ccd9410. В app и core нет встроенной Authenticode-подписи. Установщик не запускался на Mac.

## Открытые ограничения

Windows-служба TUN, WFP Kill Switch, управление системным DNS/прокси, Windows updater и Authenticode-подпись отсутствуют. Системные параметры приложение не меняет. Тесты в runner не подтверждают GUI/установку на пользовательском Windows 10/11, Credential Manager, личный Reality-сервер, браузер, сон и утечки. Это проверенная тестовая сборка локального прокси, а не полный системный VPN.

Инструкция: [вечерняя проверка](windows-test-guide.md). Рабочее приложение Mac не заменялось и VPN не прерывался.

Релиз v0.1.15 опубликован с Mac-архивами, исходниками, Windows NSIS и инструкцией. Все девять assets проверены по удалённым размерам и SHA256. Только после проверки обновлён Mac updater feed.
