# Проверка замечаний безопасности — foxVPN 0.1.8

## Исправления

- M1: перед IPC приложение проверяет установленную привязку UID/CDHash. Несовпадение теперь требует обновить компонент; другой владелец получает отдельное сообщение. Проверка готовности при запуске охватывает и ручные обновления. Авторизация root-демона не ослаблена. Управление старой сессией возвращается после установки компонента для новой сборки; обход доверия не добавлен.
- M2: удалены прямые `unwrap()` из производственного кода helper; отсутствие stdin и ошибки CString возвращаются как ошибки. Отравленный mutex журнала возвращает пустой журнал без паники. Проверено отдельным тестом. Это не обещание отсутствия паник во всех зависимостях или при исчерпании памяти.
- L3: команды импорта/экспорта больше не принимают пути от WebView. Выбор файла выполняется нативным диалогом Rust; экспорт явно обозначает наличие ключей доступа, восстановление требует нативного подтверждения. Отмена не выполняет операцию. Чтение ограничено 4 МБ, обычными UTF-8 файлами; symlink и FIFO отвергаются. WebView лишён разрешений самостоятельно открывать диалоги файлов. Компрометация WebView по-прежнему опасна для доступных ему данных приложения.
- L4: подписки принимают только публичный HTTPS. Проверяются буквальные адреса, локальные имена, все результаты DNS и каждый переход; разрешённые адреса закрепляются в клиенте, системный proxy отключён. Смешанный публичный/частный DNS отвергается. Политика консервативна: специальные и переходные диапазоны IPv6 могут быть запрещены даже при глобальной доступности. Ограничение HTTP — 25 секунд и три перехода; системное разрешение DNS может занять больше времени.

Диапазоны сверены с [IANA IPv4](https://www.iana.org/assignments/iana-ipv4-special-registry/) и [IANA IPv6](https://www.iana.org/assignments/iana-ipv6-special-registry/).

## Оставшиеся ограничения

- L1: ad-hoc CDHash связывает точную сборку, но не личность разработчика. Нужны Developer ID, подписанный Installer и notarization; сертификаты отсутствуют.
- L2: helper использует Security.framework и audit token процесса, а также Hardened Runtime. Полную проверку памяти и отсутствие всех TOCTOU не подтверждаем.
- Каталог IPC 0755 остаётся проходимым; сокет ограничен владельцем 0600, приватные данные — 0700. Это не публичное право управлять helper.
- Kill switch разрешает TCP/UDP отдельного UID ядра 62077, что нужно для прямых маршрутов и туннеля. Более узкая политика требует отдельной проработки маршрутизации.
- PKG остаётся без Developer ID Installer. Обычный bundled sing-box не получает идентичность Developer ID; сетевой runtime и helper запечатываются при сборке.
- Updater уже отвергает понижение версии и проверяет подпись с привязанной версией. Ручной откат через администратора/PKG не запрещён.

## Проверка и границы

Автоматически проверяются несовпадение привязки, отравленный журнал, небезопасные файлы, локальные/зарезервированные адреса и смешанные DNS-ответы. Нативные диалоги новой сборки и полный сценарий атакующего HTTPS/DNS-сервера на реальном устройстве отдельно не проверены. Работающий установленный VPN 0.1.7 во время доработки не отключался. Windows и физический iPhone не получили системную приёмку этой сборки.
