# Приложения без VPN на Mac

Начиная с версии 0.1.30: «Маршрутизация» → «Приложения без VPN» → «Добавить приложение». Можно найти установленную Windows App по имени или выбрать пакет `.app` штатным диалогом. С 0.1.33 список можно сохранять при работающем VPN: приложение кратко переподключится само. При ошибке оно попробует вернуть прежние настройки. Существующее подключение приложения может потребовать перезапуска.

Выбранный пакет и вложенные в него helper/XPC-процессы направляются в `direct` во всех режимах; с 0.1.31 явные правила сайтов имеют приоритет перед исключением приложения. Точный домен важнее маски, более конкретная маска важнее общей. Сопоставляется полный путь пакета с границей `/`, а не имя процесса. Перемещённое приложение нужно выбрать заново. Внешние службы вне выбранного пакета не входят в исключение. Самостоятельное приложение с похожим именем не совпадает.

Функция работает в системном TUN macOS. В режиме локального прокси список сохраняется, но не применяется; интерфейс показывает это ограничение. Общие DNS-запросы macOS не приписываются выбранной программе: DNS foxVPN остаётся защищённым. Windows сохраняет список при переносе профиля, но не применяет Mac-исключения.

Сетевое ядро сохраняет выделенный непривилегированный UID 62077. Только существующий root-компонент читает таблицу TCP/UDP и путь владельца соединения через ограниченный анонимный socketpair. Возвращаются исключительно пути внутри выбранных пакетов. В протоколе нет команд, PID, файлов для чтения или URL; кадры/размеры/таймауты ограничены. Неопределённый владелец или недоступный канал не включает direct.

Профиль и исключения сохраняются зашифрованно. Отдельное сохранение списка не заменяет остальные настройки; устаревший список, незавершённое подключение/отключение или конкурирующее изменение профиля отклоняются.

Проверка реального сетевого ядра со сбросом UID, двумя исключёнными исполняемыми файлами (основной и вложенный helper) и двумя невыбранными клиентами выполняется на disposable macOS runner. Она включает loopback-перенаправление и отдельную проверку TCP/UDP через настоящий TUN с маршрутом только 198.18.0.0/15 на disposable runner; сеть ноутбука не меняется. Это не заменяет проверку настоящей Windows App через установленный TUN и UDP/RDP на пользовательском устройстве. Проверки TCP/UDP на runner пройдены; проверка настоящей Windows App/RDP на ноутбуке после обновления остаётся отдельной приёмкой. [Отчёт 0.1.30](verification-0.1.30.md).

С 0.1.34 для торрент-клиентов действует отдельный выбор в «Обзоре» — «Трафик торрентов». По умолчанию напрямую; через VPN — только по выбору пользователя. Этот выбор выше обычных правил сайтов и исключений программ. [Как пользоваться и ограничения](torrent-routing.md).
