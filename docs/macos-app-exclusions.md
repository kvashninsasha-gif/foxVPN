# Приложения без VPN на Mac

В разрабатываемой версии 0.1.30: «Маршрутизация» → «Приложения без VPN» → «Добавить приложение». Можно найти установленную Windows App по имени или выбрать пакет `.app` штатным диалогом. Сначала отключите VPN, сохраните список и подключитесь снова. Существующее подключение приложения может потребовать перезапуска.

Выбранный пакет и вложенные в него helper/XPC-процессы направляются в `direct` во всех режимах; правило предшествует правилам сайтов. Сопоставляется полный путь пакета с границей `/`, а не имя процесса. Перемещённое приложение нужно выбрать заново. Внешние службы вне выбранного пакета не входят в исключение. Самостоятельное приложение с похожим именем не совпадает.

Функция работает в системном TUN macOS. В режиме локального прокси список сохраняется, но не применяется; интерфейс показывает это ограничение. Общие DNS-запросы macOS не приписываются выбранной программе: DNS foxVPN остаётся защищённым. Windows сохраняет список при переносе профиля, но не применяет Mac-исключения.

Сетевое ядро сохраняет выделенный непривилегированный UID 62077. Только существующий root-компонент читает таблицу TCP/UDP и путь владельца соединения через ограниченный анонимный socketpair. Возвращаются исключительно пути внутри выбранных пакетов. В протоколе нет команд, PID, файлов для чтения или URL; кадры/размеры/таймауты ограничены. Неопределённый владелец или недоступный канал не включает direct.

Профиль и исключения сохраняются зашифрованно. Отдельное сохранение списка не заменяет остальные настройки; устаревший список, активное/начинающееся соединение или конкурирующее изменение профиля отклоняются.

Проверка реального сетевого ядра со сбросом UID, двумя исключёнными исполняемыми файлами (основной и вложенный helper) и двумя невыбранными клиентами выполняется на disposable macOS runner. Она использует loopback-перенаправление без изменения сети ноутбука. Это не заменяет проверку настоящей Windows App через установленный TUN и UDP/RDP на пользовательском устройстве. До завершения этих проверок выпуск не объявляется готовым.
