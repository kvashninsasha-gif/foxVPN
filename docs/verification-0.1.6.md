# foxVPN macOS 0.1.6 — обновление из GitHub с согласием

Дата: 2026-10-04. Mac Apple Silicon. Обновление касается desktop; версия iPhone остаётся 0.1.2.

## Поведение

При запуске читается HTTPS `updates/macos.json` из этого репозитория. Это отдельный канал предварительных macOS Apple Silicon-релизов; `/releases/latest` и iOS не используются. Проверка скачивает метаданные. Окно показывает текущую/доступную версии и предлагает «Обновить», «Позже», «Пропустить эту версию». Проверку при запуске можно выключить, вручную проверить можно в настройках, включая пропущенную версию. При недоступности GitHub запуск продолжается; ошибка доступна в настройках.

Для установки нужно явное согласие и совпадение с предложенной версией. Проверяется официальный URL, версия semver, minisign-подпись Tauri с закреплённым публичным ключом и версия в подписанном trusted comment. `requireSignedVersion=true`; понижения не допускаются. Ключ подписи находится только локально вне Git/архивов и не является сертификатом Apple Developer ID.

Скачивание отменяется, ограничено 256 MiB и 180 сек; metadata check — 15 сек. Распакованный архив ограничен 512 MiB. Подготовка рядом с приложением требует права записи в каталог; пути вне foxVPN.app, абсолютные/восходящие пути и ссылки отвергаются. Проверяются Info.plist, версия/идентификатор/исполняемый файл, подпись macOS, наличие ядра и сетевого компонента. До окончания этих проверок VPN не отключается, текущая `.app` не заменяется.

Затем сохраняется текущий профиль, отключается управляемый VPN, старая `.app` перемещается в `.foxVPN-previous-<UUID>.app` рядом с приложением, устанавливается проверенная копия и запрашивается перезапуск. Ошибка второго перемещения восстанавливает старую копию. Сохранённые зашифрованные данные не перемещаются/не удаляются. Сбой запуска новой версии не вызывает автоматический откат; предыдущая копия остаётся для восстановления. Старые скрытые копии можно удалить после проверки успешного обновления.

После обновления TUN-сборки новый CDHash требует отдельного подтверждения сетевого пакета; приложение предлагает открыть системный установщик, без автоматического ввода пароля/принятия разрешений. До завершения миграции автоматическое подключение откладывается. Keychain с ad-hoc подписью может отдельно запросить доступ. Эти системные диалоги не обходятся.

Ни установленная `.app`, ни пользовательский профиль, ни работающий VPN Mac этими тестами не заменялись.

## Ограничения

Это предварительная локально подписанная сборка: Developer ID/нотарификация отсутствуют, защищённый/read-only каталог и AppTranslocation требуют ручной установки в доступный каталог. Версии до 0.1.6 нужно обновить один раз вручную. Intel macOS/Windows updater-артефакты не опубликованы и не проверены. Перезапуск реального установленного приложения, Keychain и переустановка привилегированного компонента остаются пользовательскими системными шагами; тест заменяет только изолированную копию без запуска её с личным профилем.

Прежние ограничения TUN/PF/физического сна/утечек не снимаются: [0.1.5](verification-0.1.5.md), [матрица](coverage.md). История версий и исходники сохраняются, приватный ключ и журналы не включены в релиз. Процесс выпуска следующего обновления: [updates/README.md](../updates/README.md).
