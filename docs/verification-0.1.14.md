# foxVPN 0.1.14 — восстановление TUN

## Реализовано

- Desktop передаёт выбранный сервер и до 31 резервного профиля сетевому компоненту. При включённом failover компонент циклически перебирает эту ограниченную очередь; фильтр избранных применяется и в приложении, и в helper. При выключенном failover используется только выбранный сервер. Перебор сохраняет защиту PF, не включает прямой обход VPN.
- Между неудачными попытками увеличивается минимальная пауза: 6, 12, 24, 48, 60 секунд. Успешное соединение сбрасывает счётчик. Проверки и запуск добавляют своё время к интервалу.
- Исходное имя сервера больше не заменяется навсегда на IP. Новый процесс sing-box разрешает его через bootstrap DNS-over-HTTPS к фиксированному IP выбранного DNS-провайдера с проверкой TLS. Это служебное прямое соединение ядра под выделенным UID, необходимое до установления VPN. Локальный системный DNS не используется для bootstrap TUN.
- IPC протокол 3 возвращает активный сервер. Интерфейс и сохранённый выбор синхронизируются после успешного переключения. После обновления нужен новый сетевой компонент через штатный установщик macOS.

## Ограничения приёмки

Резервы идут в порядке профилей, максимум 31; ранжирование по выбранной стратегии ещё не реализовано в TUN. Настройки и список резервов фиксируются на момент подключения; изменения применяются при следующем подключении. Переключение на реальные пользовательские резервные серверы, обрыв, смена Wi-Fi, сон, DNS/IPv6/UDP leak-test и PF counters пока не проверены на этой сборке. Установленная рабочая 0.1.13 не заменялась и не прерывалась. Это реализация этапа 2, а не завершённая системная приёмка.

Developer ID, подписанный PKG, автоматический rollback, CI, шифрование экспортируемых резервных копий и физическая проверка iPhone остаются открытыми.

## Проверки

82 теста Rust workspace и 34 теста интерфейса прошли. Проверены конфигурации настоящим закреплённым sing-box; временная локальная копия ядра совпадает по SHA256. TypeScript/Vite production build и clippy workspace/all-targets с запретом предупреждений прошли. Системное переключение серверов этими тестами не подтверждается.

Сборка macOS arm64 запечатана: подписи app/helper/core и Hardened Runtime проверены. Во время release-build сохраняется известное предупреждение rust-objcopy об отсутствующей libLLVM для удаления debug info; сборка успешно завершена.

Дополнительно прошли два явных теста: подписанный архив (установка в изолированный каталог, отмена, повреждение и неверная версия) и сборка/распаковка PKG с проверкой владельца/CDHash и отсутствия пользовательского профиля. Всего 118 успешных автоматических проверок. ZIP приложения проверен на целостность. Это не тест установки в /Applications или реального переключения VPN.

Релиз v0.1.14 опубликован на GitHub. Все семь assets проверены по удалённым размерам и SHA256; после этой проверки обновлён канал updates/macos.json.
