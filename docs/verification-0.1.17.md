# foxVPN 0.1.17 — диагностика браузерного прокси Windows

При работающем локальном ядре браузер может продолжать прямое подключение. Windows-версия теперь отдельно показывает готовность локального прокси и параметры ручного прокси Windows. Проверка читает только текущие пользовательские ProxyEnable/ProxyServer/AutoConfigURL, возвращает признаки без сохранённых адресов и не меняет реестр. Кнопка открывает фиксированный ms-settings:network-proxy. Протокольная запись считается совпадающей только для HTTP и HTTPS на активном порту 127.0.0.1.

Сохранённый PAC URL не доказывает, что сценарий включён. Интерфейс предупреждает о возможном переопределении маршрута сценарием, расширением или настройками программы. При отключённом ядре и включённом ручном прокси показано предупреждение о необходимости подключить приложение либо восстановить настройки Windows. Smart направляет .ru/.su/.рф напрямую.

Локальная проверка macOS: 89 Rust-тестов, 41 frontend-тест, TypeScript/Vite build, cargo clippy --workspace --all-targets -- -D warnings прошли. Windows-специфичная проверка реестра использует уникальный временный HKCU-ключ и не меняет реальные настройки сети. Windows runner: 72 Rust-теста и 41 frontend-тест прошли, включая реальное чтение временного ключа реестра, циклы подключения и завершение дочернего ядра после аварии родителя. NSIS x64 собран: проверены SHA256 артефакта CI, PE x64 приложения и ядра, версия 0.1.17, закреплённое ядро v1.14.2/windows-amd64.

macOS: собраны и запечатаны app/helper с Hardened Runtime; проверены версия, состав и SHA256 архивов. Два дополнительных теста прошли: установка подписанного updater-архива и отклонение подмены, создание пакета компонента с текущими владельцем и подписью. Всего 132 проверки macOS (89 + 41 + 2) и 113 Windows (72 + 41). Это не заменяет проверку маршрута браузера на личном ПК.

Windows CI: https://github.com/kvashninsasha-gif/foxVPN/actions/runs/37756029953

На личном Windows ПК через Parsec версия 0.1.16 показывала действующее локальное подключение и реальные замеры 84 мс / 5.5 Мбит/с. Это не доказывает маршрут Chrome. Позже через Parsec прочитаны параметры Windows: ручной прокси выключен, сценарий настройки выключен, автоматическое определение включено. foxVPN в этот момент отключён. Браузер не был настроен на ручной прокси foxVPN. Подключение Chrome через него и сравнение внешнего IP ещё не выполнены. Системный Windows TUN/WFP/kill switch отсутствует. Developer ID/нотарификация macOS и Authenticode Windows отсутствуют.
