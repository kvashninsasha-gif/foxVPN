# Проверки foxVPN 0.1.35

## Изменения

- Один штатный диалог «Ремонт подключения»: автоматическая проверка и подготовка конкретного плана, одна кнопка «Исправить», повторная проверка результата. Подготовка не изменяет настройки; применение использует существующие согласие, журнал, отмену и возврат.
- Подробности, необязательный ИИ и расширенный редактор плана открываются отдельно внутри того же окна. Закрытие незавершённой проверки не применяет поздний результат. Устаревший план требует повторной проверки.
- Ремонт системного Mac учитывает реальный HTTPS через системные DNS и маршруты, а не только SOCKS. При ошибке системного пути предлагается переподключение, результат перепроверяется после применения.
- Проверка связи использует два малых HTTPS endpoint по одному и тому же пути. Только точный HTTP 204 считается успехом; перенаправления/страница авторизации Wi-Fi не считаются интернетом. TLS и правила маршрутизации не ослаблены.
- Один неудачный раунд делает готовность неподтверждённой, но не перезапускает уже работающее ядро; второй раунд выполняется через короткий интервал. Успешный раунд восстанавливает статус даже при выключенном автоматическом переподключении.
- Периодическая системная HTTPS-проверка работает вне основного цикла IPC сетевого компонента. Ответ старой сети/процесса не восстанавливает статус новой сессии. Смена сети сбрасывает старый backoff. После неудачного запуска компонент снимает собственную DNS-подмену, сохраняя выбранную защиту PF.
- Ручное сравнение серверов во время активного/восстанавливаемого VPN останавливается до запуска сторонних измерительных ядер. Серверы не помечаются недоступными из-за блокировки тестового процесса защитой PF. Текущие метрики остаются в «Обзоре».

- Ядро `1.14.3-foxVPN.4`: `golang.org/x/net v0.62.0` с исправлениями GO-2026-6860/6866 и совместимые зависимости. Датированная оценка единственного неиспользуемого OpenPGP повторно проверена по полному графу; новые замечания не скрываются.

## Локальная проверка

221 Rust-тест, 125 тестов интерфейса, Clippy с `-D warnings`, TypeScript/Vite прошли. Проверены отказ первого endpoint, ответ captive portal, краткий/длительный обрыв, сохранность наблюдений серверов, ремонт при сломанном системном пути и неизменном прокси, предварительное согласие, закрытие/ошибка/устаревание диалога и повторная проверка.

Окно визуально проверено в WebKit на синтетическом профиле: краткий план и согласие находятся в одном диалоге, дополнительные действия свёрнуты. Это не сетевой тест пользовательского профиля.

Локальный аудит зависимостей прошёл: новых неподтверждённых Rust/npm замечаний нет; сохранены две ранее обоснованные Linux-only оценки. Проверка Go для обоих итоговых Mac-ядер прошла: нерешённых замечаний нет; единственная точная оценка неиспользуемого OpenPGP остаётся видимой. 19 регрессионных тестов правил аудита прошли.

## Готовые файлы и CI

Mac-приложение собрано и проверено `codesign --verify --deep --strict`. Каждое из двух ядер внутри app прошло 72 публичные конфигурации запуска; прежний отказ DNS воспроизведён как отрицательный контроль. Для настоящего подписанного архива проверены подготовка и замена временной app, отмена скачивания, отказ при подмене bytes и подписанной версии. Сетевой пакет подготовлен из того же архива в тестовом каталоге без изменения установленного компонента. Проверка loopback updater выполнена без proxy-переменных тестового процесса, чтобы запрос к локальному fixture не уходил через внешнюю сеть.

Работник локального ИИ из итогового executable прошёл шесть публичных сценариев и отказы на повреждённой модели, неизвестных полях и чрезмерном вводе; завершение при смерти родительского процесса подтверждено. Модель в архив приложения не включена. Эти проверки не открывают профиль или Keychain.

- [macOS: ядро, исключения приложений и запуск](https://github.com/kvashninsasha-gif/foxVPN/actions/runs/40873571903) — успешно для `06baea3`.
- [Интерфейс Windows/macOS](https://github.com/kvashninsasha-gif/foxVPN/actions/runs/40873571730) — успешно для `06baea3`.
- [Полный установщик Windows](https://github.com/kvashninsasha-gif/foxVPN/actions/runs/40873571799) — успешно для `06baea3`: восстановление proxy после forced parent death, original-signature cache, обновление NSIS с сохранением профиля, 72 конфигурации установленного ядра и работник ИИ из настоящей установки.

Оба исходных Go-отчёта, полные графы, локальные логи и отчёт WebKit сохранены в рабочем каталоге выпуска; публичные runtime/AI-доказательства входят в assets. Подпись обновлений использует исходный ключ, приватный ключ не публикуется. Feed и кнопки скачивания переключаются только после проверки всех опубликованных assets.

## Границы

Текущее подключение и пользовательские сетевые настройки на Mac не менялись. Не выполнялись live Stop/Start, переключение Wi-Fi, установка helper, управление AnyConnect или перенастройка VPS. Сбой конкретной Wi-Fi-сети без воспроизведения не объявляется исправленным. Windows остаётся локальным прокси. Физическая матрица смены сети/сна/утечек остаётся отдельной приёмкой.
