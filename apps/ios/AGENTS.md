# foxVPN для iPhone

Нативная iOS-версия развивается отдельно от desktop: SwiftUI + Network Extension + закреплённый sing-box Libbox. Версии и релизы имеют префикс `ios-v`; изменение только apps/ios не требует пересборки установленного macOS приложения и его helper. Не меняйте работающий VPN этого Mac при работе над iOS.

Собирайте обе платформы iPhoneOS и iPhone Simulator. Симулятор проверяет интерфейс и модели, но не заменяет системную VPN-приёмку физического iPhone. Без сертификата и provisioning с Network Extensions/App Groups/Keychain Sharing нельзя объявлять unsigned .app устанавливаемой IPA. Не отключайте подпись или системные разрешения ради установки.

Публикуйте законченные проверенные изменения в существующий GitHub согласно родительскому AGENTS.md. Не публикуйте профили, ссылки серверов, ключи, Team ID пользователя, provisioning или приватные журналы. Снимки симулятора должны использовать только открытые тестовые данные либо пустое состояние.
