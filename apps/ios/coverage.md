# Функции foxVPN для iPhone 0.1.2

Матрица описывает iOS-реализацию; desktop развивается отдельно. «Проверено» означает конкретные автоматические/локальные проверки из [отчёта](verification-0.1.2.md), а не приёмку физического VPN.

| Функция | Реализация и проверка | Оставшаяся приёмка |
|---|---|---|
| Серверы | Импорт ссылок/desktop JSON, ручное создание, полный редактор TCP/WS/gRPC TLS/Reality, поиск/группы/избранное, удаление; модели + UI | Реальные серверы каждого транспорта |
| QR и файлы | Камера, QR-изображение, JSON/text Files, экспорт QR/ссылки/JSON; декодер реального QR + UI | Физическая камера и Files на телефоне |
| Маршрутизация | VPN/direct/smart/custom, IDN/wildcard, порядок правил и DNS; Swift + Libbox | Фактические маршруты/DNS/IPv6 на телефоне |
| Переключение | Выбранный + до 7 резервов, фильтры, urltest, активный сервер и ручное измерение задержки; реальный loopback отказ сервера | Расширение iPhone, отказ всех резервов, Wi-Fi/cellular |
| Подписки | Редактор, обновить одну/все, при открытии и интервалы; лимиты/атомарность/старый список при ошибке; controller + UI | Телефонные подписки и длительное использование; фонового расписания нет |
| Скорость | Реальные 5 МБ приём + 1 МБ отправка, отмена/таймаут/проверка объёма; реальный HTTPS Simulator + тесты ошибок | Проверка именно через VPN телефона |
| Статистика | Счётчики/текущие скорости, 100 завершённых сеансов, переподключение/сброс счётчиков, журнал в памяти/Share | Фон/выгрузка/длительные сеансы телефона |
| VPN и защита | NEPacketTunnelProvider, includeAllNetworks, On Demand, явное отключение, HTTPS-проверка, общий Keychain; сборки + controller/Keychain | TUN телефона, отсутствие утечек, поведение защиты при аварии |
| Распространение | GitHub DevelopmentKit/Simulator/unsigned iPhone, исходники и SHA256; privacy manifests | Подпись Apple Developer, TestFlight, документы/ревью App Store |

Не реализованы: автоматическая синхронизация Mac/iPhone, GeoIP/GeoSite, маршрутизация отдельных приложений, пакетные потери и гарантированные фоновые обновления подписок. Локальный HTTP API desktop не переносится на iPhone. Скорость относится к текущему маршруту, задержки — к текущему набору; история после принудительного закрытия интерфейса может быть неполной. Установка и системная VPN-приёмка физического телефона ожидают учётной записи/подписи Apple Developer.
