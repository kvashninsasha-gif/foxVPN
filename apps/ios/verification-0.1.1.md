Итого: 38 XCTest-тестов без ошибок; отдельная проверка совместимости с Rust прошла. Проверка конфигурации Libbox и DNS API не заменяет реальное подключение к VLESS-серверу на телефоне. UI-тесты используют изолированное хранилище; тест Keychain создаёт и удаляет только собственную запись с уникальным service. Обычный запуск вне test mode также проверен. Пользовательские профили и работающий desktop VPN не менялись.

## Исправления, найденные проверками

В Simulator SecItem API требует подпись приложения. Отключение CODE_SIGNING_ALLOWED вызывало отказ настоящего Keychain; теперь Simulator подписывается локально. Отказ загрузки даёт возможность повторить её, а изменения сначала сохраняются и только затем появляются в интерфейсе. Мониторинг HTTPS/счётчиков привязан к текущему подключению и работает независимо от открытого экрана; старые ответы игнорируются.

На SDK 27 адаптивное меню подтверждения экспорта не показывало отмену явно. Теперь используется alert с двумя кнопками. Запрос камеры перенесён на появление экрана; Simulator сообщает о недоступной камере без запроса системного разрешения. На физическом iPhone разрешение запрашивается только при открытии сканера; сама камера пока не проверена.

HTTPS-подписки ограничены по размеру и времени, допускают только HTTPS-переадресацию. Серверы подписки заменяются атомарно с сохранением выбора и пользовательского имени/группы/избранного. Fingerprint строится из канонического JSON, а импорт использует Set вместо повторного поиска по всему списку. Экспорт предупреждает о ключах и записывается через системный выбор файла.

## Физическая приёмка — ещё не выполнена

Доступен обычный Apple ID, без действующей команды подписи Network Extensions. Нужны платная команда, provisioning приложения и расширения, App Groups/Keychain Sharing и физический iPhone. См. [Apple DTS](https://developer.apple.com/forums/thread/128767) и [установку/публикацию](publication.md). Покупка учётной записи, вход в Apple Account, TestFlight и App Store не выполнены.

После подписи проверить:

1. Импорт рабочего сервера, системное добавление VPN, подключение/отключение, сохранение профиля после перезапуска.
2. Реальный адрес выхода IPv4/IPv6 и DNS; smart-домены ru/su/рф и пользовательские exact/wildcard исключения, порядок правил.
3. TCP TLS/Reality; WS/gRPC с серверами, поддерживающими соответствующий транспорт.
4. Wi-Fi → cellular → Wi-Fi, отсутствие сети, блокировка, фон, перезагрузка; восстановление и актуальные HTTPS/счётчики.
5. Сбой сервера и отдельно расширения при includeAllNetworks on/off; проверить обход VPN и поведение On Demand. Не объявлять проверенным Kill Switch до результатов.
6. Реальную камеру, разрешение/отказ, неправильный QR, отмену; экспорт/импорт через Files и HTTPS-подписку.
7. Память и батарею при длительном использовании. Ядро имеет ограничение 40 MiB, но фактическое потребление телефона не измерено.

Полные журналы и xcresult остаются локально вне Git. В публичные снимки и тесты входят только пустое состояние и публичные синтетические данные. В релиз не включаются provisioning, приватные сертификаты, Team ID, профиль, контейнер и журналы устройства.
