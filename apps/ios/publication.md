# Как установить и опубликовать foxVPN для iPhone

Инструкция проверена по документации Apple 2026-10-03. Текущий релиз — комплект разработки: приложение и расширение собираются, автоматические проверки проходят. Физическое подключение на iPhone ещё требует подписи и приёмки. Публикация в GitHub не делает unsigned-сборку устанавливаемой на телефон.

## 1. Выбрать цель и учётную запись

Для собственного iPhone нужна платная команда Apple Developer Program, поддерживающая Network Extensions. Бесплатный Apple ID / Personal Team не поддерживает собственный Packet Tunnel Provider: [ответ Apple DTS](https://developer.apple.com/forums/thread/128767).

Для публикации VPN-сервиса в App Store Apple требует разработчика, зарегистрированного **как организация**, по [пункту 5.4](https://developer.apple.com/app-store/review/guidelines/#vpn-apps). Если цель — публичный foxVPN, оформляйте организацию сразу. Платный индивидуальный аккаунт для разработки не гарантирует публикацию VPN в магазине.

Годовая цена Apple Developer Program — 99 USD либо местная цена, указанная при регистрации. Для организации нужны юридическое лицо, D-U-N-S (кроме государственных организаций), полномочия заявителя, рабочая почта и действующий сайт на домене организации. Доступность регистрации/оплаты зависит от региона; её нужно проверить в собственной заявке. [Регистрация и условия Apple](https://developer.apple.com/help/account/membership/program-enrollment/).

Регистрацию, оплату и Apple Account владелец выполняет самостоятельно. Для совместной работы приглашайте разработчика в команду средствами Apple; пароль и коды подтверждения не передавайте.

## 2. Установить на свой iPhone через Mac

1. Скачайте **DevelopmentKit** из GitHub Releases, распакуйте и откройте `apps/ios/foxVPN.xcodeproj` в Xcode. Kit содержит готовый Libbox; при клонировании Git его нужно сначала собрать по README.
2. Добавьте свою платную команду в Xcode Settings → Accounts. В Signing & Capabilities для **foxVPN** и **FoxVPNTunnel** выберите одну команду и Automatically manage signing.
3. Зарегистрируйте доступные вашей команде Bundle ID, App Group и общий Keychain Group. Текущие имена: `ru.smartvpn.router.ios`, `ru.smartvpn.router.ios.tunnel`, `group.ru.smartvpn.router.ios`. Если нужны другие, измените согласованно `project.yml`, включая FOX_APP_GROUP/FOX_KEYCHAIN_GROUP, затем выполните `xcodegen generate` из `apps/ios`. Не публикуйте личный Team ID, provisioning и сертификаты в Git.
4. Проверьте Network Extensions → Packet Tunnel и общий App Group для двух targets. Xcode должен создать provisioning, включающий capabilities; при ошибке не отключайте подпись или entitlement.
5. Подключите разблокированный iPhone кабелем, подтвердите доверие. Включите Developer Mode в настройках телефона, если Xcode попросит. Выберите телефон и схему **foxVPN**, нажмите Run.
6. Импортируйте рабочую VLESS-ссылку или JSON-профиль foxVPN с Mac. Нажмите «Подключиться» и самостоятельно подтвердите системное добавление VPN. Выполните [физическую приёмку](verification-0.1.2.md).

Архив **Simulator** предназначен только для Simulator на Mac Apple Silicon. **Unsigned-iPhone** не является готовой IPA; его нельзя просто открыть на iPhone и установить. Для устройства собирайте подписанное приложение из проекта.

## 3. TestFlight

После проверки на физическом телефоне:

1. В [App Store Connect](https://appstoreconnect.apple.com/) создайте карточку приложения с принадлежащим команде Bundle ID, названием foxVPN и языком.
2. В Xcode выберите обычную схему foxVPN и устройство назначения для iOS archive. Сделайте Product → Archive; проверьте подпись приложения и встроенного расширения.
3. В Organizer выполните Validate App и Distribute App → App Store Connect → Upload. Это отдельная distribution-сборка, а не переименование unsigned ZIP в IPA. [Загрузка сборок Apple](https://developer.apple.com/help/app-store-connect/manage-builds/upload-builds/).
4. После обработки сборки заполните экспортную классификацию и Test Information. Добавьте себя как внутреннего тестировщика с подходящей ролью App Store Connect либо создайте внешнюю группу; внешнее тестирование проходит Beta App Review по правилам Apple.
5. На iPhone установите TestFlight из App Store и откройте приглашение. [Документация TestFlight](https://developer.apple.com/testflight/).

TestFlight служит для бета-тестирования и не гарантирует последующую публикацию в App Store.

## 4. App Store

Нужны подписанная проверенная сборка, организация и заполненная карточка: описание, категория, возрастной рейтинг, изображения, поддержка, политика конфиденциальности, App Privacy и данные о шифровании. Privacy manifests приложения и расширения уже включены в 0.1.2; перед публикацией проверьте итоговый отчёт Xcode и декларации всех SDK и условия распространения используемых компонентов. В проекте используется sing-box под GPL-3.0; GitHub-релиз содержит исходники и лицензии, но публикационные требования магазина ещё не пройдены.

Для VPN Apple требует экран с объяснением собираемых данных до использования сервиса и соответствующую политику конфиденциальности. Подготовьте отдельный тестовый сервер и доступ для ревьюера через приватные App Review Notes; реальные личные ссылки не публикуйте. Выберите территории распространения и предоставьте сведения о лицензии там, где она требуется. [Требования 5.4](https://developer.apple.com/app-store/review/guidelines/#vpn-apps).

Затем выберите сборку, заполните App Review Information и отправьте на App Review. Дата выпуска и одобрение зависят от Apple; этот репозиторий не означает, что приложение уже доступно в App Store.
